# MangaAlpha v2.6.0

本次版本带来**纯前端漫画自动裁切白边/黑边**、**书架阅读历史时间线（`/history`）**以及**全站手机竖屏排版与 Android 原生设置页全面重构**，并补齐阅读器构建期 TypeScript 类型门禁与 SSE 订阅时序修复。

## 主要变更

### 1. 内置网页阅读器升级至 `Suwayomi-WebUI r3592` 与自动裁切白边
- 将内置阅读器上游版本升级并锁定至 `Suwayomi-WebUI r3592`（SHA256 校验构建），引入纯前端自动裁切白边/黑边能力（浏览器端本地采样边界并经 `OffscreenCanvas` 输出高画质 WebP 缓存，零服务端 CPU 占用）。
- 补齐简体中文设置词条 **「自动裁切白边」**，并按设备形态设定默认策略：
  - **手机 / 窄屏（`< 900px`）**：默认开启，扫描版白边与黑边自动裁切至满屏观感；
  - **桌面 / 宽屏（`>= 900px`）**：默认关闭，保留原版双页跨页比例；
  - 均可在阅读器「设置 → 布局」中按全局默认或单部作品随时切换。
- 适配 `r3592` 的 `SubpathUtil.maybeAddAsSuffix` 与 `GET_SERVER_SETTINGS` 契约，并在阅读器构建流水线（本地、CI、Release、Android 与 Docker）中统一启用 `tsc --noEmit` 强校验，防止上游接口变动漏入线上产物。

### 2. 新增书架「历史」（`/history`）阅读时间线
- 顶栏新增 **「历史」** 页签，直接复用既有进度索引查询阅读中与已读完记录（零数据库迁移，自动遵守隐藏书库与 NSFW 隔离规则）。
- 按本机时区自然日分组展示（`今天` / `1~6 天前` / `YYYY-MM-DD`），包含封面、作品名、卷名、页码进度或「已读完」状态、具体阅读时间与书库来源。
- **同日同作品自动折叠**：同一天连续阅读同一部漫画的多卷时，时间线仅展示最新一卷，点击「▸ 当天另有 N 卷」可按需展开当天其余卷并直达阅读器或作品详情页；顶部提供按书名/卷名检索、手动刷新与按需「加载更多历史」。

### 3. 手机竖屏网页端与 Android 原生设置页全面排版优化
- 针对主流手机竖屏宽度（`360px ~ 412px`）完成全站逐页响应式加固：
  - **管理后台**：数据表禁止挤压成单字竖排并保留清晰横向滚动；管理后台 Tab 改为单行横向滑动并自动居中当前项；彻底修复展开「联合库物理子库」与「已隐藏书库」卡片在 `393px ~ 412px` 下文字被压成窄条的问题。
  - **书架与弹窗**：顶栏 6 页签单行自适应排布、Android 模式按钮防溢出；筛选区下拉选项精简文案防省略号截断；Bangumi 手动匹配弹窗按钮在移动端自动移至卡片底行；元数据编辑弹窗字段锁行告别浮动重叠。
  - **Android 原生「手机端设置」页**：重构操作按钮组为等宽间距排版并优化局域网端口输入行布局，避免窄屏下文字换行裁切。

### 4. 稳定性与打包瘦身
- 修复轻量 Komga SSE（`GET /api/v1/sse/v1/events`）先 `Flush` 后 `subscribe` 的极小窗口丢事件竞态，并补充 20 轮并发 `-race` 回归测试；为 `httpserver.New(..., nil)` 补充 discard logger 兜底。
- 服务端五平台发布归档不再附带 README 展示大图目录，发布包体积进一步精简。

## 升级说明

- 服务端、Docker 与 Android 正式包（`versionCode=2060099`）均可直接覆盖升级，数据结构与既有配置完全向后兼容，无需迁移或重新扫库。
- 若使用 Android 应用内更新覆盖安装，请确保当前已安装的是官方正式签名包。
