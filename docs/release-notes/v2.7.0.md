# MangaAlpha v2.7.0

本次版本重点带来 **Bangumi 服务端单向进度追踪器（支持 OAuth 2.0 滚动自动续期）**、**Bangumi 油猴脚本全面重构（右侧原生卡片 + 简介简中翻译切换 + 无密钥配对更新）**、**AI Agent 一键授权流与 Bangumi 防幻觉匹配指引**，以及面向公网部署的**系统性安全审计加固与 HTTPS 反向代理指南**（对局域网纯 HTTP 部署零影响）。

## 主要变更

### 1. Bangumi 服务端单向进度追踪器与 OAuth 2.0 自动续期
- **开箱一键 OAuth 2.0 授权与自动续期**：管理后台「Bangumi 刮削中心」新增内置官方 OAuth 应用一键授权（同时支持覆盖自定义 `App ID / Secret`、手动粘贴回调链接兜底，以及保留 Personal Access Token 备选并查询 `/oauth/token_status` 到期日与 30 天临期提醒）。
- **滚动自动续期防掉线**：后台每 12 小时巡检（距到期 ≤ 3 天自动刷新）、同步前 `< 24 小时` 主动刷新，遇 `401` 经互斥锁防并发重复刷新后自动续期重试，全程复用 Bangumi 网络代理。
- **全端阅读进度单向自动推送**：挂接内置阅读器、Android 端、Mihon 与 Koharia 的后续新增阅读进度（5 秒防抖合并，不批量回写历史），按单调递增卷数与完结规则增量更新状态与卷数，**绝不覆盖在 Bangumi 已写的评分、吐槽、标签，也不会降级已标记的「读过 / 搁置 / 抛弃」状态**。
- **隐私友好策略**：NSFW 作品默认跳过同步（可选改为以 `private` 私密收藏同步），另支持新建普通作品收藏时默认设为私密；作品详情页展示极简只读同步状态徽章（失败时提供单条重试按钮），后台保留最近同步记录表。

### 2. Bangumi 油猴脚本全面升级（`v2.7.2`）
- **右侧栏原生卡片排版**：将面板移至 Bangumi 条目页右侧 `#panelInterestWrapper` 收藏盒下方，复用原生 `.SidePanel` 容器与浅/深色双主题高对比样式，支持多版本分库快捷切换。
- **简介正上方「显示简中翻译 / 查看原文」切换按钮**：复用 `/api/v1/bangumi/lookup` 同一次请求按主键零额外开销返回本地中文增强离线库译文（即使本库尚未收录该漫画也能查看译文；仅当数据源为 `zh_cn` / `custom` 且译文与原文不同时出现），采用纯文本节点 + `DocumentFragment` 无损切换原 DOM，防 XSS 且浅/深色均高对比清晰可读。
- **源码彻底无密钥化与一键配对更新**：新增永久固定、完全无密钥端点 `GET /bgm/userscript/latest.user.js` 并内置 `@updateURL` / `@downloadURL`（支持在 Tampermonkey / Violentmonkey 中直接点原生「检查更新」，升级 Diff 永远干净不删 Key）；后台提供清晰的「① 安装 / 更新油猴脚本」+「② 一键生成并同步专属 Key 到油猴」（经 `#fragment` 锚点写入 `GM_setValue` 后自动抹除历史，不进服务端日志，自动轮换旧同名油猴 Key）。

### 3. AI Agent 一键授权流与 Bangumi 匹配引导闭环
- **公开只读内置指引（零私密数据泄露）**：新增免鉴权 `GET /api/agent/v1/guide` 与 `GET /api/agent/v1/playbooks/bangumi-match`（Markdown / `?format=json`），动态注入当前服务地址，内置默认 `nsfw=exclude` 与防幻觉 Bangumi 匹配 SOP（严禁凭记忆编造 `subjectId`，必须经 `/bangumi/candidates` 核实后再批量 `POST /api/agent/v1/series/batch` 绑定并输出汇总报告）。
- **OAuth Device Flow 风格一键授权页**：Agent 调用限流公开接口 `POST /api/agent/v1/auth/requests` 获取 10 分钟有效的直达确认页 `/agent-auth/<id>` 与 6 位核对码；管理员点开链接（未登录自动先登录再回跳）核对确认码后一键批准，支持轮询的 Agent 凭 `X-Poll-Token` 一次性自动领取新签发的标准 API Key（领后立即销毁内存明文，批准页同时提供手动复制兜底，密钥随时可在「账号与 API Key」吊销）。
- **管理后台一键复制卡片**：在「Bangumi 刮削中心」新增「使用 AI Agent 协助匹配未命中作品」卡片，实时展示未命中/待刮削数，一键复制动态提示词给 Claude Code / Codex / Cursor / Antigravity / OpenClaw 等任意 Agent。

### 4. Bangumi 离线库默认定时联动与细节打磨
- **默认定时随数据源自动联动**：中文增强镜像（`zh_cn`）与自定义源默认定时调整为 **每周四 `06:00`**（避开周三凌晨 06:00 翻译发布窗口），官方原版（`official`）保持 **每周三 `06:00`**；切换数据源时若未自定义其他时间则自动同步对应默认日。
- 网页底部页脚链接文案统一更新为 `MangaAlpha`。

### 5. 公网部署安全审计加固与 HTTPS 反向代理指南
- **认证与防爆破加固**：为网页登录与 HTTP Basic Auth 新增按 IP 渐进退避限流（`429` + `Retry-After`）；为 Argon2id 校验增加 4 槽并发信号量防 OOM DoS，并对不存在用户名补齐常量耗时校验防枚举。
- **边界与隐私收口**：修复 `/reader/book/<id>/*` 与 `/reader/series/<id>/*` 未登录探测漏洞；新增兼容局域网 HTTP 与原生 Komga 客户端的同源 CSRF 校验；全局添加 `X-Content-Type-Options: nosniff`、`X-Frame-Options: SAMEORIGIN`、`Referrer-Policy: same-origin`（不强推 HSTS，保持局域网 HTTP 零影响）；修复反斜杠与控制字符开放重定向、WebDAV 测试跨主机修改凭据外泄及生产态封面回环 SSRF；为 SSE 增加 64 并发上限；`Settings()` 自动屏蔽所有 `*_token` / `*_secret` / `*_password` 字段。
- **反代与无人值守初始化**：新增 `--trusted-proxies` / `FK115_TRUSTED_PROXIES` 可信代理网段配置（默认信任回环与 RFC1918/RFC4193 私网段），新增可选 `FK115_ADMIN_USERNAME` + `FK115_ADMIN_PASSWORD` 防止公网首次启动被抢注；新增独立反代部署指南 [docs/REVERSE_PROXY.md](../REVERSE_PROXY.md)（含 Caddy、Nginx、Nginx Proxy Manager 与 Cloudflare Tunnel 完整配置示例）并更新 [SECURITY.md](../../SECURITY.md) 与 [docs/AGENT_API.md](../AGENT_API.md)。

## 升级说明

- 服务端、Docker 与 Android 正式包（`versionCode=2070099`）均可直接原地覆盖升级，新增的 `bangumi_tracker_records` 表会自动无损迁移，既有书库、元数据与阅读进度完全保留。
- 若之前在浏览器中安装过旧版油猴脚本，升级后前往「管理后台 → Bangumi 刮削中心」依次点击「① 安装 / 更新油猴脚本」与「② 一键生成并同步专属 Key 到油猴」即可无缝切换至无密钥配对更新架构。
- 若之前使用默认中文增强镜像并开启了周三 `06:00` 的离线库定时检查，建议在后台确认为周四 `06:00` 以避免撞上翻译发布窗口。
