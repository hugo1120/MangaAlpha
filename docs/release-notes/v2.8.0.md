# MangaAlpha v2.8.0

本次版本重点带来 **KOReader 墨水屏双入口 OPDS v1.2 + OPDS-PSE 在线页流服务**（原生深度适配 [`opdsforcomic.koplugin`](https://github.com/hugo1120/opdsforcomic.koplugin/releases)，同时兼容标准 Komga OPDS 客户端），并完善了管理后台客户端接入推荐与登录后页脚版本号展示。

## 主要变更

### 1. KOReader 墨水屏专属 OPDS 入口（`/api/opds/v1.2`）
- **原生适配 [`opdsforcomic.koplugin`](https://github.com/hugo1120/opdsforcomic.koplugin/releases)**：采用两段式章节元数据协议（`/api/opds/v1.2/series/{seriesID}/chapter/{chapterID}/metadata`），在 KOReader 中点击章节即可直接进入在线页流阅读器，跳过多余弹窗；章节列表稳定携带序号前缀（如 `[○] 1 - Vol.01.cbz`）与 `<link rel="self">`，在正序、倒序、状态筛选及阅读历史入口下均可准确触发章末自动切下一章、前后 5 章导航与「返回章节列表」。
- **严守按需流式原则（零提前建索引 / 无整包下载）**：浏览书库、系列、历史、更新与章节列表时**绝不**提前下载或索引远程 115 / WebDAV 压缩包，也**不暴露**整本归档下载链接；仅在点击单卷打开时对单本按需建索引（并自动脱离短客户端超时在后台完成、自动校验归档版本刷新变更页数），封面与单卷缩略图复用系列封面，单页默认原图直出并支持 `?convert=jpeg` 按需转码。
- **精准双向进度同步与预加载保护**：严格区分 `updateProgress=true`（真实翻页与关闭上报）与 `updateProgress=false`（插件后台预加载，不写入阅读进度或页级进度），0-based `pse:lastRead` 精准续读；重开已读完卷自动从第 1 页起读而不误跳末页，重读前页不降级已完成状态，并联动推送至 Komga SSE 事件流与 Bangumi 进度追踪器。
- **完整浏览与筛选维度**：支持全部漫画、按书库浏览、阅读历史 / 继续阅读、最近更新、收藏夹、按类型筛选（采用查询参数避免含 `/` 类型在反代下 404）、按连载状态筛选、OpenSearch 站内搜索与多维度排序 / 状态 Facet。

### 2. 标准 Komga OPDS v1.2 + OPDS-PSE 入口（`/opds/v1.2/catalog`）
- 提供标准 Komga OPDS v1.2 目录结构（Keep Reading、On Deck、All series、Latest series、Latest books、Libraries、Collections、Read lists、Publishers 与 OpenSearch 搜索），保留自定义 `?size=` 分页参数。
- 已建索引单卷直接输出标准 1-based `pse:lastRead` 的 OPDS-PSE 页流链接；未建索引单卷通过 `/opds/v1.2/books/{bookID}` 延迟按需建索引，同样不提供整本归档下载。
- 两条 OPDS 入口均完整复用 HTTP Basic Auth / API Key 鉴权（未认证直接返回 `401` + `WWW-Authenticate: Basic`，绝不 302 跳转登录页），并严格遵守隐藏书库、联合库子层隐藏与全局 NSFW 过滤规则；`gzip` 中间件显式跳过 OPDS 页图路径保证准确 `Content-Length`。

### 3. 界面细节与客户端推荐
- **登录后页脚版本号展示**：在网页底部 `MangaAlpha` 右侧新增低调等宽版本号徽标，仅在已登录状态下由 `/admin/api/auth/status` 下发展示（未登录接口不暴露版本信息），点击可直达对应 GitHub Release 页面。
- **管理后台客户端接入指引升级**：概览页接入卡片现已同时展示 Komga 根地址、KOReader 专属地址（`/api/opds/v1.2`）与标准 Komga OPDS 地址（`/opds/v1.2/catalog`），并附带 **[Koharia](https://github.com/Mister-album/Koharia)**（推荐 Android Komga 客户端）、**[Mihon](https://mihon.app/)** 与 **[`opdsforcomic.koplugin`](https://github.com/hugo1120/opdsforcomic.koplugin/releases)** 直达链接；同步更新 `README.md` 客户端说明与开源生态致谢。

## 升级说明

- 服务端、Docker 与 Android 正式包（`versionCode=2080099`）均可直接原地覆盖升级，无破坏性数据库变更，既有书库、元数据与阅读进度完全保留。
- 在 KOReader 中使用本服务时，建议安装 [`opdsforcomic.koplugin`](https://github.com/hugo1120/opdsforcomic.koplugin/releases) 并在插件内添加 `http://<服务器IP>:25600/api/opds/v1.2`（填写 MangaAlpha 管理员账号密码即可）。
