# MangaAlpha v2.9.0

本次版本带来两项实用更新：**加密压缩包（ZIP / CBZ 与 RAR / CBR）有限支持**，以及 **Windows 原生系统托盘模式（彻底告别常驻黑窗）**。

## 主要变更

### 1. 加密压缩包有限支持（ZIP / CBZ + RAR / CBR）
- **纯 Go 流式解密（零新增依赖、`CGO_ENABLED=0`）**：
  - **ZIP / CBZ**：原生支持 Traditional PKWARE **ZipCrypto**（Store / Deflate）与 **WinZip AES-128 / AES-192 / AES-256**（AE-1 / AE-2，含 PBKDF2-HMAC-SHA1 密钥派生与 HMAC-SHA1-80 完整性校验），继续保持 115 / WebDAV / 本地 / SMB 全存储源按需流式读取，绝不下载整包。
  - **RAR / CBR**：支持非固实、单卷加密 RAR4 与 RAR5（含仅加密文件数据 `-p` 与同时加密文件头 `-hp`）。
- **网页阅读器弹窗解锁与同文件夹自动复用**：
  - 在内置网页阅读器打开或切换到加密漫画卷时，自动弹出深色密码输入弹窗（支持显示/隐藏密码与密码错误内联提示）；验证解密通过后自动记住密码并与该漫画绑定。
  - 打开**同一文件夹**下的其它加密文件（覆盖普通多卷目录、单本 One-Shots 目录及联合库）时，会自动按「直绑 → 同系列 → 同文件夹」优先级尝试已记住的密码，命中后自动绑定并无缝阅读；已解锁的漫画在第三方 Komga 客户端与 KOReader / OPDS 入口下同样可直接阅读。
  - 后台缩略图批处理与下一卷索引预读遇到未解锁加密包时静默跳过，避免产生多余报错。
- **管理后台密码管理与缓存联动清理**：
  - 在 `/admin` → **安全设置** 标签页新增「**已记住的压缩包密码**」管理面板（仅管理员登录后可见，密码绝不写入日志或诊断导出），按密码分组展示绑定的作品与卷名，默认 `••••••••` 掩码并支持点击显隐。
  - 支持单卷「**解绑**」、单组「**删除此密码**」与「**全部清空**」；删除或清空后会同步清除对应书籍的索引缓存与已解密页面磁盘缓存（加密页响应同时设置 `Cache-Control: private, no-store`），确保立即恢复锁定状态。

### 2. Windows 系统托盘常驻（无 PowerShell / 终端窗口）
- **原生 GUI 静默运行**：Windows 发布包现统一以 `-H=windowsgui` 编译单个 `mangaalpha.exe`，双击启动后直接常驻系统托盘（不弹出 PowerShell / Windows Terminal 黑窗、不闪烁，且**不写入任何开机自启注册表项**），同时保留首次启动自动打开网页书架的便捷体验。
- **托盘交互与日志查看**：
  - 左键单击托盘图标打开网页书架（带双击防抖，避免误开多个标签页）；右键菜单提供当前版本/端口状态、**打开网页书架**、**打开管理后台**、**打开数据目录**、**查看运行日志**（自动写入 `<数据目录>\mangaalpha.log`，5 MiB 滚动轮转）与**退出 MangaAlpha**（优雅停服并清理托盘图标）。
  - 重复双击启动遇到端口占用时，弹出友好提示框询问是否直接打开网页书架；支持 `explorer.exe` 重启后自动重建托盘图标与 Windows 关机/注销时优雅退出。
  - 需要作为无界面后台服务（如 NSSM / 任务计划程序）运行时，可传入 `--no-tray` 参数或设置环境变量 `FK115_NO_TRAY=true` 保持纯无头模式。

## 升级说明

- 服务端、Docker 与 Android 正式包（`versionCode=2090099`）均可直接原地覆盖升级，数据库自动幂等创建 `archive_passwords` 与 `archive_password_bindings` 表，既有书库、元数据、封面与阅读进度完全保留。
- Windows 用户覆盖升级 `mangaalpha.exe` 后，下次直接双击即可进入系统托盘模式，原有 `%LOCALAPPDATA%\fake-komga-115\data` 数据目录保持不变。
