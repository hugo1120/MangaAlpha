# MangaAlpha v3.0.0「长夜」

> 愿人类的夜晚，会是个平静祥和的时代。
>
> <p align="right">—— 初濑野阿尔法，《横滨购物纪行》</p>

MangaAlpha 迎来 3.0.0 大版本更新——「**长夜**」。本次版本的核心升级为**完整的多用户权限与数据隔离体系**，让自托管书架既能作为个人主力漫画库，也能安全、体面地分享给家人与朋友共同使用，同时带来全新大版本代号展示与安全加固。

## 主要变更

### 1. 完整多用户与权限隔离体系
- **主管理员 + 普通用户双角色模型**：
  - 保留唯一主管理员账号（负责书库、存储源、刮削、密码本、AI Agent 与全局配置），支持在 `/admin` → **用户管理** 标签页创建、编辑、重置密码、停用/启用、强制下线及删除普通用户。
  - 普通用户仅由管理员创建（不开放自助注册、不可自行修改用户名），服务端对所有管理接口、元数据修改、加密包明文密码本及 AI Agent 接口严格执行 `403` RBAC 拦截；停用或删除账号后，其活跃会话、API Key、Komga / OPDS Basic 登录及实时 SSE 连接立即失效。
- **精细化书库与 NSFW 访问控制**：
  - 支持为每位普通用户分配「全部可见书库」或精确到指定书库的访问白名单，同时覆盖网页书架、Komga API、OPDS / KOReader、内置阅读器与联合库视图（联合库响应自动隐藏无权成员库信息，且任意 NSFW 物理源均会保守保护联合库分级）。
  - 支持按账号独立控制「是否允许访问 NSFW 作品（`allow_nsfw`）」；获得授权的用户可在个人设置中独立开关 NSFW 显示（`show_nsfw`），互不影响其他账号。
- **全链路个人数据完全隔离**：
  - 每位用户拥有完全独立的**阅读进度、进度重置记录、阅读历史、在读列表、收藏夹、阅读列表、内置阅读器偏好（`localStorage` 按账号隔离并自动兼容主管理员旧数据）、登录会话、个人 API Key、油猴配对 Key 及 Bangumi 进度追踪器**（支持各自绑定自己的 Bangumi OAuth / PAT 账号）。
  - 获得书库授权的普通用户可在阅读加密漫画卷时自助输入密码解锁，但无权查看或管理管理员的明文密码本。
- **全新个人「账号设置」页面（`/account`）**：
  - 普通用户点击顶栏「账号设置」即可查看可见书库、自助修改密码、开关个人 NSFW 视图、管理自己的 API Key 与活跃设备会话、复制个人客户端接入地址（Komga / KOReader OPDS / 标准 OPDS）以及配置独立的 Bangumi 单向进度追踪器。

### 2. 大版本代号「长夜」与页脚视觉优化
- **3.x 大版本代号展示**：登录后页脚统一采用简洁无边框排版 `MangaAlpha · v3.0.0 长夜`，悬停版本号可查看完整版本信息与「长夜」出处引语（未登录态与公开接口严格不暴露版本号与代号）。
- **内嵌轻量化字体子集**：内嵌仅 `1.1 KB` 的霞鹜文楷（LXGW WenKai，SIL OFL 1.1）最小字形子集 WOFF2，零外部 CDN 依赖，在局域网与离线环境下均可稳定呈现「长夜」字形。

### 3. 安全性与稳定性加固
- 强化多用户场景下的跨账号防护：受权限保护的漫画页与缩略图响应统一采用 `Cache-Control: private, no-store`；全站写请求与内置阅读器增加账号上下文校验（`X-FK115-User-Id`），防止多标签页切号错写进度或凭据；扩展浏览器 HTTP Basic Auth 的同源 CSRF 校验。
- 登录防爆破限流升级为「按 `(IP, 账号)` + Per-IP 兜底」双层策略，普通用户正常登录不会重置管理员失败计数；密码重置同步吊销目标用户全部会话与 API Key。
- Bangumi OAuth 回调与手动换码绑定发起会话与用户身份，后台刷新与同步队列增加用户启用状态与权限校验，避免解绑或删号后的数据竞态。

## 升级说明

- **平滑原地升级**：服务端、Docker 与 Android 正式包（`versionCode=3000099`）均可直接原地覆盖升级。
- **零数据损失迁移**：首次启动 v3.0.0 时，SQLite 数据库将自动执行幂等迁移，将既有管理员账号、全部阅读进度、收藏夹、阅读列表、登录会话、API Key 及 Bangumi 追踪配置无缝归属至主管理员名下，并保留既有 OPDS 收藏夹链接索引（`rowid`）。建议在跨大版本升级前按习惯备份数据目录中的 `fake-komga-115.db`。
