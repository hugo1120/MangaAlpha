# MangaAlpha v3.0.1

本版本修复内置阅读器将含「漫画」中文标签的作品误判为竖式条漫的问题。

## 修复内容

- **修复内置阅读器自动切换竖式条漫误判**：
  - 清理上游阅读器 `MangaType.MANHUA` / `MANHWA` 多语言类型表中混入的通用词 `'漫画'` 与 `'만화'`，避免带「青年漫画」「少年漫画」「少女漫画」等中文类型标签的常规日漫被误识别为长条漫（Webtoon）并强制切为竖向滚屏。
  - 将内置阅读器「自动条漫模式（`shouldUseAutoWebtoonMode`）」默认值调整为关闭，保持桌面双页 / 手机单页左右翻页默认行为；需要自动识别真正带 `条漫 / Webtoon / Long Strip / 韩漫 / 国漫` 标签作品的用户仍可在阅读器设置中手动开启。
- **修复 GitHub Release 正文标题重复**：构建发布工作流在提取首行标题后自动剥离正文首行一级标题，避免 Release 页面标题显示两遍。

## 升级说明

- 服务端、Docker 与 Android 正式包（`versionCode=3000199`）均可直接原地覆盖升级，无数据库结构变更。
