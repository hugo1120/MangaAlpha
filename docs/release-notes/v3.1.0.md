# MangaAlpha v3.1.0

本版本带来首批社区贡献特性（感谢 [@hugo1120](https://github.com/hugo1120) 提交 PR #3、#4、#5！），并围绕**特大型漫画库搜索性能**、**全局管理台与个人设置分离**以及 **Android 客户端交互可靠性** 完成了系统级升级。

## 主要变更

### 1. CJK 繁简 / 日文异体字 / 假名互搜 + 独立无内容 FTS5 倒排索引（PR #3）
- **全面覆盖多文字变体**：新增共享包 `internal/cjk`，融合 Apache-2.0 OpenCC 字表与精选漫画异体字映射（4,543 组 100% 幂等折叠规则）及平片假名双向规范化，支持繁体/简体（`灌籃高手` ↔ `灌篮高手`、`東立` ↔ `东立`）、日文新旧字体（`進撃の巨人` ↔ `进击的巨人`）、全角半角与平片假名（`葬送のフリーレン` ↔ `葬送のふりーれん`）双向互搜，且不改动原始展示标题。
- **面向特大库的高性能索引架构**：不向核心 `series` / `books` 表加列，改为独立无内容 FTS5 倒排索引（`series_search_fts` / `books_search_fts`，`content='', contentless_delete=1`）配合条件触发器脏队列、非阻塞后台分批构建、VACUUM 锚点自愈与瞬态锁退避重试。
  - 在约 9.7 万系列 / 52.3 万本册（~2.0 GB SQLite）的真实大库下实测：服务启动零阻塞（`Open()` 约 25ms），后台建索引约 44 秒，数据库体积增量仅约 +2.8%（+55.5 MiB），繁简/假名/多条件搜索耗时稳定在 2.5ms ~ 11.3ms。
- **Bangumi 离线索引同步受益**：离线标题索引 schema 自动本地升级至 v4，繁简与日文异体字匹配命中率同步提升。

### 2. Bangumi 匹配评分明细与近失候选展示（PR #4）
- 评分引擎新增 `ScoreCandidateDetailed`，完整输出标题分、平台、系列、版本后缀、作者、汉化组、短标题惩罚与热度加减分明细；精确单字标题（如 `嘘`）免除误伤性短标题惩罚并防止版本后缀剥离后的近似词误触发。
- 自动匹配未达阈值时返回评分最高的 Top 3 近失候选与阈值说明，在系列详情页的 Bangumi 匹配弹窗中可展开「评分明细」逐项核对并一键手动绑定；同步加固弹窗并发操作互斥保护。

### 3. 个人网页显示数量自定义（PR #5）
- 支持按账号独立配置书架每页数量及首页「继续阅读 / 最近更新 / 最近添加」展示数量（基于 Komga `client_settings` 的 `webui.*` 命名空间持久化，跨设备同步，浏览器本地缓存按用户 ID 严格隔离、失败自动回滚）。

### 4. 全局管理台与个人账号设置清晰拆分
- **管理员个人设置收敛至 `/account`**：点击顶栏用户胶囊直达个人账号设置页，集中管理管理员账号/密码修改、个人 NSFW 视图、个人网页显示数量偏好、个人 API Key、个人 Bangumi 追漫追踪器与活跃会话。
- **`/admin` 聚焦 7 个纯全局管理标签页**：概览、存储源、书库、Bangumi 刮削（含全局自定义 OAuth App）、任务队列、系统设置（并入全局加密包密码本）与用户管理；历史路径 `/admin?tab=security` 自动跳转至 `/account`。

### 5. 修复 Android 客户端删除/确认操作无响应与 WebDAV 删除加固
- **全站统一应用内确认弹窗**：新增独立高层级 `confirmModal`（支持嵌套在弹窗之上叠放、移动端居中展示、键盘焦点锁定以及切页/切号自动取消），将全站全部 17 处原生 `window.confirm()` 替换为深浅色风格一致的应用内确认框，彻底修复 Android WebView 中删除 WebDAV 账号、删书库、删用户、清缓存等按钮静默失效的问题；Android WebView 下的诊断日志导出按钮改为直达原生「手机端设置」。
- **Android 底层补齐 `WebChromeClient`**：为内置 WebView 补充带回环域校验与一次性防死锁生命周期保护的 `onJsAlert` / `onJsConfirm` / `onJsPrompt` 兜底。
- **WebDAV 账号删除加固**：数据库校验与删除改用 `BEGIN IMMEDIATE` 事务（同步加固 WebDAV 书库创建防删建竞态）；若账号仍被书库引用（含已隐藏书库与联合库物理子库），返回明确的中文 `409` 提示并列出具体占用的书库名称。

## 升级说明

- **平滑原地升级**：服务端、Docker 与 Android 正式包（`versionCode=3010099`）均可直接原地覆盖升级，无需手动迁移。
- **后台无感建索引**：首次启动 `v3.1.0` 时，Bangumi 离线索引（如已安装）会自动原地升级至 v4，全文检索 FTS5 索引会在后台低开销分批构建，构建期间服务立即可用并自动回退兼容查询。
- 升级前建议按习惯备份数据目录中的 `fake-komga-115.db`。
