# MangaAlpha v3.1.1

本版本修复新增 115 书库时目录浏览无法进入子文件夹并回退根目录的问题，同时加固 115 扫库分页与防误清空保护。

## 修复与改进

- **修复 115 目录浏览器点击子文件夹回退首页**：
  - 修正前端 115 目录选择抽屉读取子目录 ID 的字段名（由不存在的 `fileId` 修正为 `id`，并在后端 `/admin/api/115/folders` 同步兼容输出 `id` 与 `fileId`），彻底解决点击任意文件夹发送空 `cid` 回退到 115 根目录以及点「选用」写入空值的问题。
  - 为 115 目录选择抽屉补齐路径面包屑、「选用当前目录」按钮、加载失败时的「返回上级」按钮以及防并发乱序保护。
- **加固 115 目录分页与空根目录防误删保护**：
  - `oneonefive.ListDirectory` 分页偏移量改为按实际返回条数递增，当远端提前返回空页但总数未齐时明确报错而非静默截断，避免漏扫。
  - 为 115 扫库补齐与本地/SMB、WebDAV 一致的「已有作品书库根目录返回 0 条目防误删」保护及防循环目录 ID 校验。

## 升级说明

- 服务端、Docker 与 Android 正式包（`versionCode=3010199`）均可直接原地覆盖升级，无数据库结构变更。
