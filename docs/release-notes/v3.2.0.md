# MangaAlpha v3.2.0

本版本将「Bangumi 刮削」全面升级为开放式**多源元数据刮削中心**，新增纯 Go 声明式元数据市场、只读离线 SQLite Sidecar 引擎、中文标签翻译词典、社区脱敏映射包、Bangumi NSFW 授权检索与封面支持，并完成多项前后端体验打磨。

## 主要变更

### 1. 声明式元数据市场与纯 Go 离线 Sidecar 引擎
- **声明式元数据仓库（`mangaalpha-repo-v1`）**：支持在管理后台订阅标准 `repo.json` 清单或手动添加本地/远程自定义数据源，后台内置社区推荐仓库一键预填（需管理员确认后才发起订阅，不自动请求）。
- **纯 Go 流式解压与增量更新检测**：引入纯 Go `klauspost/compress/zstd`（全平台保持 `CGO_ENABLED=0` 零 CGO 依赖），支持 `.zst` / `.zstd` / `.gz` / `.zip` / `.sqlite` 流式下载解压，并支持 GitHub Releases `updated_at` / 体积与 HTTP `ETag` / `Last-Modified` 增量变更检测。
- **双规范只读离线 SQLite + Sidecar 索引**：支持 `mangaalpha_meta_v1` 标准单表与 `gallery_v1` 通用四表离线图库，以只读模式打开上游库并在旁构建 FTS5 全文 + 封面 SHA-1 指纹 Sidecar 索引，同时支持解析归档内嵌 `ComicInfo.xml` 与 `galleryinfo.txt` 元数据；`gallery_v1` 严格按 `Non-H` 分类豁免规则标注 NSFW。
- **中文标签翻译词典（`tag_translation_text_v1`）**：支持关联标签翻译词典并按源选择纯中文（`zh`）、中英双语（`bilingual`）或原始标签（`raw`）展示模式。
- **社区脱敏映射包（`mangaalpha_mapping_v1`）与脱敏导出**：当所有离线数据库均未命中时自动由已启用的社区映射包兜底（兼容空映射包零报错）；后台支持按书库与绑定来源预览并导出脱敏 `.ndjson` 映射包（默认严格排除 NSFW 与隐藏书库，自动剥离路径、IPv4/IPv6、凭据与 URL）。详见 [docs/METADATA_SOURCES.md](../METADATA_SOURCES.md)。

### 2. 书库多源顺延优先级链、统一批量刮削与流水线协同
- **按顶层书库自定义顺延链**：为每个顶层书库（含联合书库）自由配置 `#1 → #2 → ...` 离线源顺延顺序（未配置时默认使用内置 Bangumi 源）；后台批量刮削与任务记录彻底合一并持久化保留历史，新增无已就绪离线源预检防止误刷；默认纯离线极速匹配，仅在显式勾选后才启用单线程限速防封熔断的低速在线补全。
- **作品详情页跨源检索与绑定**：作品「修改匹配」弹窗支持在 Bangumi 与已就绪扩展数据源之间自由切换检索、按 ID/规范链接精准绑定及独立解除扩展源绑定；自动批量任务（含全量重刮）统一保护手动绑定、AI Agent 绑定、升级存量绑定与字段锁定。
- **定时流水线与外部封面协同**：定时流水线升级为多源增量刮削（仅配置扩展离线源也可正常执行）；外部封面支持熔断限速、URL 版本化磁盘缓存、条目级 NSFW 权限校验与失败自动回退首卷第 1 页；自动补首卷封面任务同步跳过已绑定外部封面作品。

### 3. Bangumi 目录解析加固与 NSFW 授权封面/搜索
- **目录尾部噪点清洗加固**：增强扫图组、压制后缀、平台/出版杂项剥离能力，进一步提升常规漫画自动匹配命中率。
- **Bangumi NSFW 授权访问与 5 道防泄露防线**：当当前用户（或回退主管理员）已绑定 Bangumi OAuth / PAT 且开启对应 NSFW 视图权限时，支持携带授权拉取 Bangumi NSFW 条目封面与实时搜索；严格落实跨用户 NSFW 权限隔离、仅向 `https://api.bgm.tv` 发送凭据、防重定向泄密、`Cache-Control: private, no-store` 与脱敏日志保护。

### 4. 界面打磨与问题反馈入口
- **「元数据刮削」中心重排与文案统一**：内置「Bangumi 离线索引库」与统一「启动批量自动刮削」前置，社区市场默认隐藏重复的内置 Bangumi 条目，全站统计与筛选统一为「已匹配 / 未匹配 / 元数据已匹配」。
- **移动端与细节打磨**：恢复移动端右上角用户胶囊入口（`.user-pill`），页脚分隔点升级为柔和纯 CSS 正圆，移除管理概览重复的油猴脚本卡片，为前台「合并相同 Bangumi ID」补充范围说明，在 `/account` 补充 Koharia / Mihon / KOReader 客户端官网链接，并新增 `.github/ISSUE_TEMPLATE/` 与后台问题反馈卡片。

## 升级说明

- **平滑原地升级**：服务端、Docker 与 Android 正式包（`versionCode=3020099`）均可直接原地覆盖升级，无需手动迁移。
- **幂等大库迁移**：首次启动自动创建 `metadata_repos`、`metadata_sources`、`library_metadata_sources` 三张表并为 `series_metadata` 增补扩展绑定列及部分索引（10 万级系列大库实测迁移约 1.6 秒，零数据改动）；升级存量绑定自动受保护不被全量重刮覆盖。
- 升级前建议按习惯备份数据目录中的 `fake-komga-115.db`。
