# MangaAlpha v3.2.1

本版本为 `v3.2.0` 的网络兼容与排障体验热修复版本，解决路由器透明代理（Fake-IP）环境下订阅元数据仓库及同步外部元数据源被误拦截的问题，并补齐脱敏诊断日志与分类错误提示。

## 主要修复

### 1. 兼容路由器透明代理 Fake-IP 与双栈 DNS
- **放行公网域名解析得到的透明代理 Fake-IP**：在直连模式下，当请求目标为合法公网域名且本地/路由器 DNS 返回标准透明代理 Fake-IP 地址段（IPv4 `198.18.0.0/15`、IPv6 `fc00::/18`）时允许正常建连；当同时存在 Fake-IPv6 与 IPv4 候选地址时优先尝试 IPv4，避免在纯 IPv4 容器环境中等待 IPv6 超时。
- **双栈 DNS 屏蔽占位容错**：自动跳过 DNS 返回的 `0.0.0.0` 与 `::` 未指定占位记录（绝不对占位地址拨号），避免在屏蔽 AAAA 的 DNS 环境下因单条空记录导致整次连接失败；若全部解析记录均为未指定地址则继续拦截。
- **不降低原有内网 SSRF 防护**：继续严格拦截所有字面量内网/Fake-IP URL（如 `http://198.18.0.1/`、`http://[fc00::1]/`）、内网主机名（`localhost`、`*.local`、`*.internal`、`*.lan` 等）以及真实私网/回环/链路本地/CGNAT/局域网 ULA（`fd00::/8`）混合 DNS 解析结果。

### 2. 元数据错误提示与脱敏诊断日志完善
- **可读分类提示**：元数据仓库订阅、刷新与数据源同步失败时，不再将底层原因笼统折叠为 `Could not fetch upstream metadata.` 或 `metadata source synchronization failed`，改为区分返回安全且清晰的中文提示（涵盖网络安全策略拦截与显式代理引导、无效代理 URL、清单 JSON 格式无效、上游 HTTP 状态码、超时、DNS / TLS / 连接错误与校验和不匹配）。
- **脱敏诊断事件**：为元数据仓库订阅/刷新、源同步与外部封面异常（SSRF 拦截、熔断）补充 `diagnostics` 诊断记录与服务端日志，新增 `SSRF_BLOCKED` 等错误分类；诊断导出严格脱敏，不泄露 URL、原始 IP、代理凭据或本地路径。
- **错误分类去噪与锁优化**：`diagnostics.ClassifyError` 在关键字匹配前先剥离 URL，避免请求路径中的 `.sqlite` / `.zip` 等文件名干扰错误归类；源同步收尾先释放状态写锁再执行诊断落盘，避免并发导出诊断包阻塞元数据读取。

## 升级说明

- **平滑原地升级**：服务端、Docker 与 Android 正式包（`versionCode=3020199`）均可直接从 `v3.2.0` 或更早版本原地覆盖升级，无数据库结构变更。
- 若极少数环境使用了自定义非标 Fake-IP 段（例如私网段）或自建内网镜像，仍可在后台「网络代理设置」中填写显式 HTTP / SOCKS5 代理地址使用。
